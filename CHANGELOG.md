## v1.0.1 — 2026-09-24 — hardened candidate (Turn 10)

- **A09-01:** count pending buffer acquisitions before any Python callback; unwind
  callback and FillInfo failures. Block transfer while any root or derived view
  retains the slot. Do not solve the race by copying the payload.
- **A09-02:** make the exporter cyclic-GC-aware; separate native cleanup state from
  public wrapper cycles. Do not release storage underneath live aliases.
- **A09-03:** correct full/source inventory coverage for license, audit, hidden
  metadata and source revisions; keep verification read-only.
- **A09-04:** make shared-memory name encoding's unsigned promotion explicit for
  strict GCC O1 ASan/UBSan builds.
- **A09-07:** use resurrection-aware finalization; do not expose freed exporter
  storage through a user unraisable hook.
- **A09-08:** retain acquisition responsibility before ctypes; poison/retain
  endpoints when asynchronous interruption leaves the native outcome uncertain.
- Preserve queue and wire semantics. The archived 1.0.0 audit remains a record of
  the vulnerable release, not a declaration that these fixes were absent forever.
